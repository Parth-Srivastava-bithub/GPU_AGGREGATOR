# 🏢 Company Overview

**[To be figure out] — Unified GPU Deployment & Monitoring Platform**

---

## 🎯 Mission & Vision

Make renting and running GPUs across cloud providers as simple as clicking one button — no juggling five dashboards, no duct-taped Slack alerts, no manual price hunting.

Long-term vision: become the single control plane ML engineers and small AI teams use to find, deploy, and monitor compute — regardless of which provider it's running on underneath.

---

## ❗ Problem We're Solving

ML engineers and researchers renting GPUs across providers (RunPod, Novita, Vast.ai, Hyperstack, etc.) today deal with:

- No live, unified pricing across providers — comparing means opening 5 tabs
- Existing comparison tools (e.g. gpus.io) only *monitor and redirect* — you still leave the site to deploy
- Manual, hacky monitoring setups (e.g. Betterstack + Slack notifications) that are noisy and not built for this
- No single place to deploy, track, and manage pods/instances across providers

People are solving this today with tools stitched together — it works, but it's messy and slow.

---

## 🛠️ Services We Offer

- **Live price monitoring** across multiple GPU cloud providers, normalized so you can actually compare apples to apples
- **Direct deployment** from our dashboard using providers' own APIs (RunPod GraphQL, Novita REST, etc.) — no redirect, no leaving the site
- **Unified monitoring** of active pods/instances — status, cost, uptime — in one view
- **Agent-assisted deployment** — describe what you need, agent picks provider/GPU and deploys it

## 👥 Target Clients

- Teams currently duct-taping together multiple provider dashboards + alerting tools

## 🎯 Why We're Different

Existing tools (gpus.io, computeprices.com) are **monitors that redirect out**. We're building **monitor + deploy + manage in one place** — using providers' own APIs directly, not scraping or linking out.
